# GDP Dashboard

A clean and interactive dashboard for exploring global GDP statistics across countries.

## Overview
This project provides a simple Streamlit-based dashboard for visualizing GDP data and comparing economic indicators across countries in an accessible, easy-to-understand layout.

## Features
- Country-wise GDP visualization
- Interactive dashboard experience
- Clean presentation of regional data
- Easy local setup with Streamlit

## Tech Stack
- Frontend: Streamlit
- Data: Python-based dashboard app
- Deployment: Streamlit Cloud

## Demo
- Live Demo: https://gdp-dashboard-template.streamlit.app/

## Run Locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Project Goal
To present economic data in a clear and visually engaging way with a simple, effective dashboard workflow.

## My Contribution
This project demonstrates data storytelling and dashboard design using a lightweight, readable interface for public data exploration.
